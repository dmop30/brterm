# 画面設計 v1

確定日: 2026-09-13 / 対応 Issue: #11 / 根拠: `docs/requirements.md` 4.1・4.3・4.5・7 章

利用者の確認を得た版。**この文書と実装がずれたら、実装ではなくここを先に直す。**
図つきの提案版は Artifact にある（https://claude.ai/code/artifact/e77f1231-b7f7-464f-b384-b54104c7fc40）。

## 決めたこと

|            | 内容                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------- |
| 画面構成   | 左レール（48px）+ 側パネル（236px）+ ワークスペース（タブ + 中身 + ステータスバー 24px）     |
| タブ       | **端末とエディタを同じ列**に並べる。Ctrl+Tab で巡回                                          |
| 側パネル   | 常時表示。Ctrl+B と畳むボタンで開閉。**720px 以下では最初から畳む**                          |
| 配色       | 暗い配色と明るい配色の 2 つ。既定は `system`（OS に従う）                                    |
| 強調色     | 1 色だけ（接続・選択・フォーカス）。状態は正常・注意・危険の 3 色                            |
| 状態表示   | **色だけに頼らない。** 形（丸・帯）と文言を必ず添える                                        |
| 書体       | IBM Plex Sans JP + IBM Plex Mono（Google Fonts）。読めない環境では OS 標準の和文書体に落ちる |
| 破壊的操作 | 確認ダイアログに**ホスト名とパスを必ず出す**。既定フォーカスは「取り消す」                   |

## トークン

実体は `src/client/styles/global.css`。値はそこを見る（この表は写し）。

| 役割               | 暗い配色  | 明るい配色 |
| ------------------ | --------- | ---------- |
| 地                 | `#151A21` | `#F6F7F9`  |
| 面（パネル・タブ） | `#1B2129` | `#FFFFFF`  |
| レール             | `#10151A` | `#ECEFF3`  |
| 境界線             | `#2A313A` | `#D7DCE3`  |
| 文字               | `#E3E8EE` | `#1A1F26`  |
| 補助文字           | `#8B96A3` | `#5D6876`  |
| 強調               | `#4FA3C7` | `#1C6E8C`  |
| 正常               | `#6FB286` | `#2F7D55`  |
| 注意               | `#D9A441` | `#8A5D0C`  |
| 危険               | `#D3646F` | `#B3303C`  |

字の大きさ: 画面文言 13px / 端末・エディタ 12.5px / ステータスバー 11.5px / 見出し 15px。
余白 4・8・16・24px。角丸 4px。境界線 1px。影は重ねる面（ダイアログ）だけ。

## キーボード

| キー                      | 動作                               |
| ------------------------- | ---------------------------------- |
| Ctrl+Tab / Ctrl+Shift+Tab | 次 / 前のタブへ（端で折り返す）    |
| Ctrl+T                    | 端末を開く                         |
| Ctrl+W                    | 作業中のタブを閉じる               |
| Ctrl+B                    | 側パネルを畳む / 出す              |
| Ctrl+S                    | 保存（エディタ。#20 で有効になる） |
